# my-mango packages

# Формат: секции в квадратных скобках, по одному пакету на строку.
# Комментарии начинаются с #. Транзитивные зависимости pacman/yay подтянут сами.

# [bootstrap]    собирается install.sh, если yay ещё нет
# [core]         минимальный набор для mango/waybar/скриптов

# [apps]         обычные приложения
# [apps-aur]     AUR-приложения
# [system]       база, ядро, сервисы, login/boot
# [system-aur]   AUR-пакеты для железа
# [flatpak]      flatpak-приложения
# [services]     systemd-сервисы (system)
# [user-services] systemd-сервисы (user)
